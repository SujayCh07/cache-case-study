# Redaction Checklist

Use this checklist before copying the case study into a public repository.

## Confirm These Are Excluded

- [ ] Production source code.
- [ ] `.env` values, keys, tokens, cookies, and credentials.
- [ ] Production URLs or infrastructure identifiers.
- [ ] Real candidate, student, recruiter, company, partner, or customer data.
- [ ] Emails, phone numbers, resumes, screenshots, or logs with private information.
- [ ] Exact API routes, schemas, table definitions, storage paths, or auth/session payloads.
- [ ] Exact ranking formulas, scoring weights, thresholds, and prompts.
- [ ] Internal pricing, private roadmap material, or confidential launch details.
- [ ] Unrelated projects or work from outside this case study.

## Final Review

- [ ] All diagrams are conceptual and public-safe.
- [ ] Tech badges link only to public technology branding/assets.
- [ ] No placeholder markers remain.
- [ ] No fabricated metrics, users, revenue, customers, awards, or technical results were added.
- [ ] The repo reads as an architecture case study, not as implementation documentation.
