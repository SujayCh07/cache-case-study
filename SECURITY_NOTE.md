# Security Note

This repository is a public architecture case study, not the CacheAI production codebase.

The diagrams, docs, and examples are sanitized. They describe system design and technical direction without exposing source code, secrets, production infrastructure, full schemas, exact API surfaces, ranking formulas, prompts, private user data, logs, or partner details.

The architecture is intentionally simplified so it can be shared publicly while preserving the confidentiality and security of the production system.
