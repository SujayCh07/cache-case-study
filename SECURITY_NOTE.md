# Security Note

This repository is a public engineering case study for Cache. It is not the production codebase.

The diagrams, documents, and examples in this repository are intentionally simplified. They describe product architecture, workflow design, and engineering approach at a high level without exposing production implementation details.

This repository does not include:

* Production source code
* Private student, recruiter, company, or partner data
* Credentials, keys, tokens, cookies, `.env` values, or production URLs
* Full database schemas or migrations
* Exact API routes, request payloads, or internal service contracts
* Proprietary prompts, ranking formulas, scoring weights, thresholds, or matching logic
* Production logs, auth/session payloads, debugging traces, or monitoring data
* Internal roadmap, pricing, customer details, or confidential business information

Any diagrams, screenshots, examples, or workflows are public-safe representations and may differ from the production system.

The goal of this repository is to communicate engineering judgment and system design while preserving the confidentiality and security of the platform.
